# Video originals (gitignored)

This folder holds two encode masters that are **not in git**, by design. See `.gitignore` lines 12–13 (`reference/downloaded`, `reference/video-originals`).

The live `web/` encodes **are** in git. The site plays without this folder. These files are only needed to re-encode those two films at different settings.

A clone without these files cannot regenerate those two films.

The other thirteen encode masters sit next to their `web/` encodes in `public/` and are committed. This folder is not a gap for the rest of the site.
