# HBW website — recovered baseline

Local reconstruction of the public site at [https://www.hbw.works/](https://www.hbw.works/). This is a fidelity baseline, not a redesign.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/`
- `/projects`
- `/projects/sub-3` (and koja, bar-closed, our-boy-roy, chris-sisarich, bistro-nido)
- `/studio`
- `/collections`

- `/intake/start`
